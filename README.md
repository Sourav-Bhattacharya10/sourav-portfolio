# Sourav Bhattacharya - Professional Portfolio

A modern, responsive, and high-performance portfolio website showcasing the professional journey, skills, and achievements of Sourav Bhattacharya, a Senior Full-stack Developer with over 9 years of experience.

## 🚀 Tech Stack

- **Frontend:** React 19, TypeScript
- **Build Tool:** Vite
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Styling:** CSS3 (Custom modules/styles)
- **Package Manager:** Yarn

## ✨ Features

- **Responsive Design:** Optimized for all screen sizes from mobile to desktop.
- **Interactive UI:** Smooth animations and transitions powered by Framer Motion.
- **Experience Timeline:** Detailed professional history across multiple top-tier organizations (Optum, PwC, TCS, etc.).
- **Skills Showcase:** Categorized technical expertise in Frontend, Backend, Database, and Cloud technologies.
- **Education & Awards:** Academic background and professional recognitions.
- **Contact Integration:** Direct links to LinkedIn, GitHub, and email.

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- Yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sourav-Bhattacharya10/sourav-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd sourav-portfolio
   ```
3. Install dependencies:
   ```bash
   yarn install
   ```

### Development

Run the development server:
```bash
yarn dev
```
The application will be available at `http://localhost:5173`.

### Build

Create an optimized production build:
```bash
yarn build
```
The output will be generated in the `dist/` directory.
